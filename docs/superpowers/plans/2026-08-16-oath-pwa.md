# Oath PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **REQUIRED READING for every task:** `docs/oath-spec.md` (the full product spec). This plan defines interfaces, math, and acceptance criteria; the spec defines the product. When this plan and the spec conflict on math, THIS PLAN WINS (it corrects one spec typo, noted in Task 4).

**Goal:** Implement the complete Oath spec — a dark retro life-RPG — as an installable web app (PWA) that runs fully offline in the browser, with a Claude-powered nutrition agent.

**Architecture:** Event-sourced core: `QuestCompletion` + `XPEvent` records are the source of truth; day scores, streaks, character stats, vigor and siege state are recomputed caches. Pure deterministic game engines (`src/game/*`) with 100% unit tests; IndexedDB (Dexie) persistence (`src/data/*`); a zustand store as the single composition point (`src/app/store.ts`); React UI on top. No backend — the Claude nutrition call goes browser-direct to the Anthropic API with a user-supplied key.

**Tech Stack:** Vite 5 · React 18 · TypeScript (strict) · Vitest · zustand · Dexie 4 · fake-indexeddb (tests) · @anthropic-ai/sdk (browser mode) · @fontsource fonts · vite-plugin-pwa · custom SVG for all charts and the knight (no chart/3D libraries).

## Global Constraints

- **Palette (exact, from spec §2):** bg gradient `#080B08 → #060907`, deepest `#050705`; panels `#0A100B`, borders `#1C2E22`, hairlines `#14211A`; neon green accent `#46FF7D`; text greens `#D6EFDB` / `#8FAF97` / `#5E7565` / `#52685A`; amber `#E8B54D` (main quest / PR / Legend only, max one per screen); ember red `#E25B4A` (boss/danger/FAILED only); text on green fills `#04140A`. - **Visual language:** diamond checkboxes, segmented XP bars with glow, rank letter in rotated-square diamond, panels with 1px border + 2px neon corner ticks (amber ticks for main quest), page frame with inset border + 4 corner ticks, optional CRT scanline/vignette overlay, 20px geometric stroke icons, 5-square difficulty pips. Math (spec §5): base = `100 · Σ(wᵢcᵢ)/Σ(wᵢ)` over required (non-optional) items; if no required items base = 100. Bonus = `min(5, Σ over completed optionals of (w·c·0.5))`. Total capped 100, round half-up. Gates: `S` needs score≥90 AND every required hard/elite item has credit ≥ 1; `S+` needs score===100 AND zero failed required items. If a gate fails, demote to the highest rank the score allows below the gated one (score 100 failing S+ gate → S if S gate passes, else A).
